This repository contains data relevant to the inventory of lichens in the nature reserve Fiby urskog, Uppland. The study was published in: von Hirschheydt, G., Ekman, S. & Westberg, M. (2021) Unik lavflora i Fiby urskog. Fauna och Flora 116: 2–18.

fiby.R: code for generating randomly placed plots in a 100 m grid in Fiby Urskog nature reserve, incl. check whether the entire plots are inside the reserve.

Fiby_polygon_vertices*: vertices describing the shape of the reserve, original and rounded to nearest meter.

Plot coordinates.xlsx: coordinates of inventoried plots (i.e.,  output from fiby.R). Transferred from OSF on 20 Nov 2026.

Plot tree composition.xlsx: registered composition of trees in each plot (in the end not used for anything in the study). Transferred from OSF on 20 Nov 2026.
